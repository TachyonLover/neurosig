# NeuroSig
- This is a web application that will allow users to import EEG signal CSV files and analyze them.

## Planned Milestones
1. Create a blank React page
2. Sketch main page layout and components
3. Display sample EEG measurements in React
4. Basic FastAPI endpoint
5. Retrieve measurements from FastAPI in React
6. Implement CSV parsing and validation
7. Add CSV upload interface
8. Display uploaded signal as a chart
9. Calculate and display basic signal statistics
10. Test and polish MVP

## Potential Features
- Light and dark mode toggle
- Analyzed file persistence
- Info page for help analyzing EEG signals
- User accounts
- AI summary

## Tech Stack
- React
- FastAPI
- Python
- SQLite (planned)
